安装教程

💻 电脑端 — Tampermonkey

  1. 安装 Tampermonkey 浏览器扩展
  2. 点击上方「立即安装」按钮
  3. Tampermonkey 会自动弹出安装确认，点击安装即可
  4. 打开 chat.qwen.ai，右下角出现 [+] 悬浮球即为生效

📱 手机端 — Via 浏览器（安卓 / iOS）

Via 浏览器原生支持油猴脚本，无需额外安装扩展。

  1. 在 Via 浏览器中点击上方「立即安装」按钮
  2. Via 会自动识别为油猴脚本，弹出安装提示
  3. 点击确定，脚本即刻生效
  4. 打开 chat.qwen.ai，右下角出现 [+] 悬浮球即为生效

💡 如果没有自动弹出提示，可以：Via 菜单 → 设置 → 脚本 → 添加脚本 → 导入

🧩 Chrome / Edge 扩展（实验性）

⚠️ 扩展版本暂未完成完全测试，可能存在 Bug，推荐优先使用油猴脚本版本。

  1. 从 GitHub Release 或 Gitee Release 下载 qwen-studio-beautify-extension.zip
  2. 解压 zip 文件到本地文件夹
  3. Chrome 地址栏输入 chrome://extensions/，Edge 输入 edge://extensions/
  4. 打开右上角「开发者模式」→ 点击「加载已解压的扩展程序」→ 选择解压后的 extension 文件夹
  5. 打开 chat.qwen.ai 即可生效

🎯 使用方法

安装后打开 Qwen Studio，右下角会出现一个可拖动的悬浮球 [+]，点击打开设置面板：

  • 背景 切换图片/视频/无背景
  • 透明度 滑块调节背景透明度
  • 亚克力 开关毛玻璃效果
  • 主题色 HSV 色盘选择颜色
  • 字体 下拉选择预设字体
