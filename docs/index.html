安装教程

Edge 浏览器安装

Edge 浏览器内置扩展商店，可直接安装 Tampermonkey。

  1. 打开 Edge，访问 Edge 扩展商店 — Tampermonkey，点击「获取」安装扩展
  2. 安装完成后，浏览器右上角会出现 Tampermonkey 图标，确认扩展已启用
  3. 点击本页上方的「立即安装脚本」按钮
  4. Tampermonkey 会自动弹出安装确认页面，点击「安装」
  5. 打开 chat.qwen.ai，页面右下角出现 [+] 悬浮球即为安装成功

Chrome 浏览器安装

Chrome 推荐从 Tampermonkey 官网下载安装，不依赖应用商店。

  1. 访问 Tampermonkey 官网（tampermonkey.net），点击页面中的「Download」
  2. 在下载页面找到 Chrome 区域，点击下载 .crx 安装包 备选方案：如果官网下载缓慢，可前往 GitHub Releases 下载最新版 .crx 文件
  3. 在 Chrome 地址栏输入 chrome://extensions/ 并回车，打开扩展管理页
  4. 打开页面右上角的「开发者模式」开关
  5. 将下载好的 .crx 文件直接拖拽到 Chrome 扩展管理页面中
  6. 弹出确认对话框，点击「添加扩展程序」完成安装
  7. 点击本页上方的「立即安装脚本」按钮
  8. Tampermonkey 会自动弹出安装确认页面，点击「安装」
  9. 打开 chat.qwen.ai，页面右下角出现 [+] 悬浮球即为安装成功

手机端 — Via 浏览器（安卓 / iOS）

Via 浏览器原生支持油猴脚本，无需额外安装扩展。

  1. 在 Via 浏览器中点击本页上方的「立即安装脚本」按钮
  2. Via 会自动识别为油猴脚本，弹出安装提示
  3. 点击「确定」，脚本即刻生效
  4. 打开 chat.qwen.ai，页面右下角出现 [+] 悬浮球即为安装成功

如果没有自动弹出提示，可以手动导入：Via 菜单 → 设置 → 脚本 → 添加脚本 → 将脚本内容粘贴进去 → 保存

使用说明

安装成功后，打开 chat.qwen.ai，页面右下角会出现一个可拖动的悬浮球 [+]。点击它即可打开设置面板。

背景

点击「选择图片」上传本地图片作为页面背景，也可粘贴视频 URL 使用视频背景，支持切换「无背景」模式

透明度

拖动滑块调节背景透明度（0% ~ 100%），数值越低背景越淡，推荐 30% ~ 60%

亚克力

开关毛玻璃效果。开启后，聊天气泡、侧边栏、输入框等组件会显示半透明模糊背景

主题色

通过 HSV 色盘选择主题色，拖动 H（色相）、S（饱和度）、V（明度）三个滑块实时调整全局色调

字体

从下拉菜单选择预设字体，包含霞鹜文楷、思源黑体、更纱黑体等 20+ 中英文字体，选中即生效

暗色模式

支持浅色/深色手动切换，可开启明暗独立背景功能，为不同模式分别配置不同背景

悬浮球操作：点击打开/关闭设置面板；长按可拖动到屏幕任意位置，松手后自动固定。所有设置会自动保存到本地，刷新页面后依然生效。

常见问题

安装后没有看到悬浮球？

请确认：① Tampermonkey 扩展已启用（浏览器右上角图标应为亮色）；② 脚本已在 Tampermonkey 管理面板中显示为「已启用」状态；③ 当前访问的网址是 chat.qwen.ai。如果仍不显示，尝试硬刷新页面（Ctrl+Shift+R）。

Chrome 拖入 .crx 文件提示「无法安装」？

这是 Chrome 的安全策略限制。解决方法：① 确保已开启「开发者模式」；② 尝试将 .crx 文件后缀改为 .zip 并解压，然后在扩展管理页点击「加载已解压的扩展程序」选择解压后的文件夹。

亚克力效果卡顿或不显示？

毛玻璃效果（backdrop-filter）依赖 GPU 加速。如果卡顿：① 关闭其他占用 GPU 的标签页；② 在浏览器设置中确认「硬件加速」已开启；③ 如果仍卡顿，可在面板中关闭亚克力效果，仅保留透明背景。

脚本更新后如何升级？

Tampermonkey 默认会自动检查脚本更新。也可手动更新：打开 Tampermonkey 管理面板 → 找到本脚本 → 点击「编辑」旁的更新图标。或直接重新点击本页的「立即安装」按钮覆盖安装。

如何卸载脚本？

打开 Tampermonkey 管理面板（点击浏览器右上角 Tampermonkey 图标 → 管理面板），找到「Qwen Studio Beautify」，点击右侧删除图标即可。
